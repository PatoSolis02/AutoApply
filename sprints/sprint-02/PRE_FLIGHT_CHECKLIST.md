# Sprint 02 Pre-Flight Checklist

Complete this before opening any Sprint 02 thread.

## Git/Workspace

- Baseline commit exists on the starting branch.
- Trunk branch confirmed as `codex/integration`.
- All Sprint 02 worktrees exist and are isolated.
- Each thread has a dedicated branch and directory.
- Old Sprint 1 threads are archived/left idle (not reused for coding).
- Thread knows commit cadence requirement (commit after each logical unit).

## Runtime/Tooling

- Runtime baseline reviewed in `docs/TOOLING_BASELINE.md`.
- Python version confirmed against baseline.
- Node/npm version confirmed against baseline.
- Canonical test commands confirmed and documented.

## Contracts

- `docs/BUILD_CONTRACT.md` reviewed.
- `docs/SAFETY_COMPLIANCE.md` reviewed.
- Sprint objective scope reviewed from `sprints/sprint-02/PLAN.md`.

## Handoff

- Thread knows required output format.
- Thread knows required handoff file path.
- Thread knows to stop and report if contract changes are needed.
