# AutoApply --- Development Phases

## Phase 1 --- Application Tracker

Goal: Capture and store job postings locally.

Deliverables: - SQLite schema - FastAPI endpoints - Extension
integration - Dashboard listing

Exit Criteria: Capture and view 10 LinkedIn jobs successfully.

------------------------------------------------------------------------

## Phase 2 --- Resume Tailoring & PDF

Goal: Generate tailored resume PDFs.

Deliverables: - Profile editor - Tailoring engine (keyword alignment) -
HTML resume template - PDF export & storage

Exit Criteria: Clean resume PDF generated per job.

------------------------------------------------------------------------

## Phase 3 --- Truth & Audit Hardening

Goal: Prevent unsupported claims.

Deliverables: - Rule enforcement - Diff view - Claims mapping

------------------------------------------------------------------------

## Phase 4 --- Fit Scoring

Goal: Prioritize high-fit jobs.

Deliverables: - Keyword extraction - Fit score (0--100) - Gap analysis
